# تقويم شندي — Shendy Life Calendar

تطبيق ويب شخصي لتنظيم الحياة اليومية والأسبوعية وفق منظومة شندي: محاور سبعة،
قواعد أسبوعية واضحة، دورة علمية A/B/C، سبع وظائف بزنس متتابعة، ومواد كلية محددة.

هذا المشروع **محلي أولًا (Local-first)**: لا يوجد تسجيل دخول ولا خادم ولا مزامنة
سحابية. كل بياناتك تُحفَظ في متصفحك عبر `localStorage`.

## المزايا

- عروض تقويم: **شهر / أسبوع / يوم / أجندة**.
- تنبيه دائم بميزانية الوقت (3 + 10 + 3 + 3 + 2 + 3 = 24 ساعة بلا هامش).
- دعم المهام **غير الموقّتة** بدون اختراع أوقات.
- قوالب المحاور السبعة، وقوالب إدارة **الصحة والإدارة** كتصنيفين منفصلين بهدف
  مشترك.
- قوالب العلم حسب دورة A/B/C، ووظائف البزنس السبعة المتتابعة دون إعادة العد.
- مواد الكلية الست، مع ربط افتراضي قابل للتعديل بين `Computer Organization`
  و `English` يوم الأربعاء (75 + 45 دقيقة).
- **مشروع نشط واحد فقط**، مع حقل فارغ حتى تحدده بنفسك.
- تسجيل الزمن الفعلي، الحالة (لم يبدأ / قيد التنفيذ / منجز / مؤجل)، المخرجات،
  الخطوة التالية، والعائق.
- تصدير JSON وCSV، واستيراد JSON مع تحقق قبل الحفظ.
- واجهة عربية RTL، خط Tajawal، ولوحة ألوان أبيض/أسود/رمادي فقط.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # مخرجات dist/ جاهزة للنشر الثابت
npm test         # اختبارات الوحدة (Vitest)
npm run typecheck
npm run lint
```
