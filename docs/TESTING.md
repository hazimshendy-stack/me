# الاختبارات

## التشغيل

```bash
npm test
npm run test:watch
```

## ما يُختبَر

- **`cycle.test.ts`** — أنماط A/B/C مطابقة للمرجع؛ غياب جلسات العلم يومي
  الجمعة والسبت؛ انتقال C → A؛ استمرارية ترتيب وظائف البزنس عبر الدورات.
- **`businessFunctions.test.ts`** — ترتيب الوظائف السبع؛ التتابع الصحيح؛
  عدم اختراع معنى لـ DI.
- **`college.test.ts`** — يوم كل مادة؛ تقسيم الأربعاء 75 + 45.
- **`date.test.ts`** — تحويل ISO؛ بداية الأسبوع يوم الأحد؛ مدد الوقت؛
  التحقق من HH:MM؛ «يوم التركيز».
- **`export.test.ts`** — جولة JSON ذهابًا وإيابًا؛ رفض JSON غير صالح؛
  رفض بنية بدون events؛ CSV بعنوان أعمدة وبقيم عربية مقتبَسة.

## اختبارات قبول يدوية

- `npm run dev` يبدأ التطبيق، و`npm run build` يُكمل بنجاح.
- التنقل بين شهر/أسبوع/يوم/أجندة يعمل.
- إضافة/تعديل/حذف حدث يبقى بعد إعادة التحميل.
- استيراد JSON غير صالح يُرفض دون فقدان البيانات.
- تصدير نسخة احتياطية واستعادتها يعملان.
- التطبيق يعمل على شاشة الهاتف دون كسر النماذج.
- الجمعة والسبت لا تحتويان جلسات علم/كلية/مشروع مجدولة في القوالب.

## الحدود

الاختبارات الآلية لا تُغطي UX البصري. تحقّق يدويًا من التفاعلات والتفاعل
مع لوحة المفاتيح والقارئ الشاشي عند الحاجة.
