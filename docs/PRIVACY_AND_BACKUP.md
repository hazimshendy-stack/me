# الخصوصية والنسخ الاحتياطي

## أين تُحفظ البيانات

- جميع الأحداث تُحفظ في `localStorage` بمفتاح `shendy-life-calendar:v1`.
- لا يوجد Backend ولا مزامنة سحابية. لا يتم إرسال شيء إلى الإنترنت.

## حدود هذه المقاربة

- `localStorage` **لا يزامن** البيانات بين الأجهزة أو المتصفحات.
- مسح بيانات المتصفح قد يمحو كل بيانات التقويم.
- فتح التطبيق في نافذة خاصة (incognito) لا يضمن استمرار البيانات بعد الإغلاق.

## النسخ الاحتياطي

- **تصدير JSON**: من الإعدادات → «تصدير JSON». يحتوي على كل الأحداث
  والإعدادات والمشروع النشط.
- **تصدير CSV**: من الإعدادات → «تصدير CSV». مناسب لجدول `Daily Log`.

## الاستعادة

- من الإعدادات → «استيراد JSON»، ألصق محتوى النسخة الاحتياطية.
- يُتحقق من صحة الملف قبل الحفظ. الملفات غير الصالحة تُرفض دون المساس
  ببياناتك الحالية.
- الاستيراد **يستبدل** البيانات الحالية بعد تأكيد صريح.
