# النشر على GitHub

## الرفع التلقائي عبر setup.js

1. ثبّت `gh` (GitHub CLI).
2. `gh auth login` مرة واحدة.
3. `node setup.js` (بدون `--no-github`).
4. عند النجاح، ستجد رابط المستودع في `SETUP_REPORT.md` وفي مخرجات الطرفية.

الافتراضي هو مستودع **private**. استخدم `--public` فقط إذا رغبت بمستودع عام.
لا تُرفع بيانات التقويم الفعلية إلى Git؛ فهي محفوظة محليًا في المتصفح.

## GitHub Actions

يشمل المشروع `.github/workflows/ci.yml` الذي يبني ويختبر عند push وpull
request، مع تثبيت الاعتماديات عبر lockfile عند توفره.

## GitHub Pages

- `--deploy-pages` تُهيّئ النشر عندما يكون ذلك ممكنًا.
- إعداد Vite يستخدم `base: './'` حتى يعمل النشر على مسار فرعي.
- النشر العام يُعدّ خطوة منفصلة عن الرفع الخاص، ولا يُفعَّل تلقائيًا.

## قيود

- إذا لم تكن أدوات GitHub متاحة، يُنشئ السكربت المشروع محليًا بنجاح ويطبع ما
  ينقص بالضبط.
- لا يُدفع بـ `--force`، ولا يُحذف فرع أو مستودع.
